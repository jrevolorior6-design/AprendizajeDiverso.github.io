01

Exponentes y radicales

Propiedades, simplificación y operaciones

Conceptos clave

Una potencia representa multiplicaciones repetidas. Un radical permite encontrar una raíz. Para bases distintas no se suman exponentes, y las propiedades deben aplicarse respetando sus condiciones.

aᵐ · aⁿ = aᵐ⁺ⁿ　 |　 aᵐ / aⁿ = aᵐ⁻ⁿ (a ≠ 0)
(aᵐ)ⁿ = aᵐⁿ　 |　 a⁰ = 1 (a ≠ 0)
√(ab) = √a · √b, para a,b ≥ 0

Ejemplo: simplificar x³ · x⁴ / x²

  1. Multiplicamos potencias de la misma base: x³ · x⁴ = x⁷.
  2. Dividimos potencias de la misma base y restamos exponentes: x⁷ / x² = x⁷⁻².
  3. Resultado: x⁵, con x ≠ 0 en la expresión original.

Radical: √72 = √(36 · 2) = 6√2.

02

Expresiones racionales

Simplificación, operaciones y restricciones

Conceptos clave

Una expresión racional es un cociente de polinomios. El denominador nunca puede ser cero. Se factoriza para identificar factores comunes y restricciones.

(ab)/(ac) = b/c, si a ≠ 0 y c ≠ 0
a/b + c/d = (ad + bc)/bd

Ejemplo: simplificar (x² − 9)/(x² + 3x)

  1. Factorizamos: x² − 9 = (x − 3)(x + 3).
  2. Factorizamos el denominador: x² + 3x = x(x + 3).
  3. Cancelamos el factor común (x + 3), sin olvidar las restricciones originales.
  4. Resultado: (x − 3)/x; restricciones: x ≠ 0 y x ≠ −3.
03

Ecuaciones

Resolución algebraica y comprobación

Conceptos clave

Resolver una ecuación significa encontrar los valores de la variable que hacen verdadera la igualdad. Se puede sumar, restar, multiplicar o dividir ambos lados por la misma cantidad (no cero al dividir).

Si ax + b = c y a ≠ 0, entonces x = (c − b)/a

Ejemplo: 3(2x − 1) = 15

  1. Distribuimos: 6x − 3 = 15.
  2. Sumamos 3 a ambos lados: 6x = 18.
  3. Dividimos entre 6: x = 3.
  4. Comprobamos: 3(2·3 − 1) = 3(5) = 15.
  5. Solución: x = 3.
04

Modelado con ecuaciones

Planteamiento y resolución de problemas

Cómo modelar un problema

Leer el enunciado, definir la incógnita, traducir la relación a una ecuación, resolver y comprobar que la respuesta tenga sentido en el contexto.

Ejemplo: entradas para una actividad

Una entrada de adulto cuesta Q30. Se venden 12 entradas y se recaudan Q300. ¿Cuántas entradas de adulto se vendieron si las demás eran infantiles de Q20?

  1. Sea x el número de entradas de adulto; las infantiles son 12 − x.
  2. Planteamos: 30x + 20(12 − x) = 300.
  3. Distribuimos: 30x + 240 − 20x = 300.
  4. Reducimos: 10x = 60; por tanto, x = 6.
  5. Se vendieron 6 entradas de adulto y 6 infantiles.
05

Geometría de coordenadas

Distancia, punto medio y plano cartesiano

Fórmulas principales

Distancia: d = √[(x₂ − x₁)² + (y₂ − y₁)²]
Punto medio: M = ((x₁ + x₂)/2, (y₁ + y₂)/2)

Ejemplo: A(2, 1) y B(6, 4)

  1. Distancia: d = √[(6 − 2)² + (4 − 1)²].
  2. d = √(16 + 9) = √25.
  3. Distancia: 5 unidades.
  4. Punto medio: M = ((2 + 6)/2, (1 + 4)/2).
  5. M = (4, 2.5).
06

Rectas

Pendiente, ecuación, intersecciones, paralelas y perpendiculares

Fórmulas principales

Pendiente: m = (y₂ − y₁)/(x₂ − x₁), si x₂ ≠ x₁
Forma pendiente-intersección: y = mx + b
Paralelas: misma pendiente. Perpendiculares: m₁m₂ = −1 (si ambas pendientes existen).

Ejemplo: recta por (1, 2) y (3, 6)

  1. Calculamos m = (6 − 2)/(3 − 1) = 4/2 = 2.
  2. Usamos y = mx + b: 2 = 2(1) + b, entonces b = 0.
  3. Ecuación: y = 2x.
  4. Intersección con el eje y: (0, 0). La recta también pasa por el origen.
07

Funciones

Concepto, notación, evaluación, dominio y rango

Conceptos clave

Una función asigna a cada entrada del dominio exactamente una salida. f(x) se lee “f de x”. El dominio reúne entradas permitidas y el rango, los valores de salida obtenidos.

Si f(x) = 2x + 3, entonces f(a) = 2a + 3.

Ejemplo: evaluar f(4) si f(x) = 2x + 3

  1. Sustituimos x por 4: f(4) = 2(4) + 3.
  2. Multiplicamos: 8 + 3 = 11.
  3. f(4) = 11.

Para esta función lineal, si el dominio es ℝ, el rango también es ℝ.

08

Análisis de funciones

Lectura de gráficas, intervalos, máximos y mínimos

¿Qué debemos observar?

Al analizar una gráfica, identificamos dominio, rango, intersecciones con los ejes, intervalos donde crece o decrece, y máximos o mínimos. Las respuestas dependen de la función y del intervalo considerado.

Ejemplo: f(x) = −(x − 2)² + 4

  1. Está en forma de vértice: f(x) = a(x − h)² + k.
  2. El vértice es (h, k) = (2, 4); como a = −1, abre hacia abajo.
  3. El máximo valor es 4, cuando x = 2.
  4. Para hallar las raíces: 0 = −(x − 2)² + 4; entonces (x − 2)² = 4.
  5. Intersecciones con x: x = 0 y x = 4. Rango: y ≤ 4.
09

Funciones cuadráticas

Gráfica, vértice, eje de simetría e intersecciones

Fórmulas principales

f(x) = ax² + bx + c, a ≠ 0
Eje de simetría: x = −b/(2a)
Vértice: (−b/(2a), f(−b/(2a)))
Discriminante: Δ = b² − 4ac

Ejemplo: f(x) = x² − 4x + 3

  1. a = 1, b = −4, c = 3. Eje: x = −(−4)/(2·1) = 2.
  2. Vértice: f(2) = 4 − 8 + 3 = −1, así que es (2, −1).
  3. Como a > 0, la parábola abre hacia arriba y tiene mínimo −1.
  4. Factorizamos: x² − 4x + 3 = (x − 1)(x − 3).
  5. Cortes con x: (1, 0) y (3, 0). Corte con y: (0, 3).
10

Funciones polinomiales y ceros reales

Comportamiento, gráficas, división y determinación de ceros

Conceptos clave

Una función polinomial es una suma de términos con potencias enteras no negativas de x. Sus ceros reales son los valores de x para los que f(x) = 0; gráficamente, corresponden a cruces o contactos con el eje x.

Teorema del factor: si f(r) = 0, entonces (x − r) es factor de f(x).

Ejemplo: encontrar los ceros de f(x) = x³ − 4x

  1. Igualamos a cero: x³ − 4x = 0.
  2. Factor común: x(x² − 4) = 0.
  3. Diferencia de cuadrados: x(x − 2)(x + 2) = 0.
  4. Igualamos cada factor a cero.
  5. Ceros reales: x = −2, x = 0 y x = 2.
